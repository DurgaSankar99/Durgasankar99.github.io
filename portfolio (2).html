Projects

Brain tumor detection with deep learning

Nov 2025 – Mar 2026

  • Trained an EfficientNetV2-S model to sort brain MRI scans into glioma, meningioma, pituitary tumor, or no tumor. It uses two-phase transfer learning: a frozen backbone first, then fine-tuning from layer 100.
  • Added Grad-CAM heatmaps so a radiologist can see which region drove each prediction, not just the result.
  • Built a Flask web app: upload an MRI and get a prediction with confidence scores and a full class ranking.
  • Built a tf.data pipeline with checkpointing and early stopping, and fixed version conflicts and normalization mismatches so the served model matches the trained one.
  • Validated with a confusion matrix and accuracy, precision, recall and F1.
